## Phase 1: Pendle Ecosystem

### Protocol Overview

Pendle Finance is the leading on-chain **yield tokenization** protocol. It takes yield-bearing assets
(SY = Standardized Yield tokens) and splits them into two tradable components:

- **PT (Principal Token):** Redeemable 1:1 for the underlying at a fixed maturity date. Provides
  fixed-rate exposure; no intermediate yield distributions. Effectively a zero-coupon bond.
- **YT (Yield Token):** Receives ALL yield generated by the underlying until maturity, then expires
  at **zero value**. Provides leveraged exposure to the yield rate.

## Phase 2: YT Mechanics — How Yield Tokens Actually Work

### Core Equation

```
Deposit SY (e.g., 1 SY-sUSDe worth $1) →
  PT-sUSDe   = redeemable for $1 at maturity (Dec 2026)
  YT-sUSDe   = earns all yield from $1 sUSDe until Dec 2026; then = $0
```

### Implied APY Formula (Pendle docs)

```
implied_apy = (1 + yt_price / pt_price) ^ (365 / days_to_maturity) - 1
```

The YT price is a **small fraction** of the underlying, creating leveraged yield exposure.
A 2pp change in implied APY produces a disproportionately large % change in YT value.

### YT Return Logic

```
net_return_pp = avg_realized_underlying_APY - implied_APY_at_entry
```

If realized underlying APY > implied APY paid → profit.
If realized underlying APY < implied APY paid → loss.
If exactly equal → break-even (excluding gas/slippage).

### Time Decay

Under **constant implied yield**, YT price decays linearly to zero at maturity.
The table below shows $500K YT position value over a 180-day lifecycle:

| Days Remaining | Position Value | % of Initial |
|---|---|---|
| 180 (entry) | $500,000 | 100.0% |
| 150 | $416,667 | 83.3% |
| 120 | $333,333 | 66.7% |
| 90 | $250,000 | 50.0% |
| 60 | $166,667 | 33.3% |
| 30 | $83,333 | 16.7% |
| 15 | $41,667 | 8.3% |
| 7 | $19,444 | 3.9% |
| 1 | $2,778 | 0.6% |

**Critical implication:** "Sitting" in YT while implied yield stays flat = losing half your position
value by mid-duration. Capital recovery depends entirely on accumulated yield distributions — which
are proportional to the realized underlying APY being above the implied rate.

### Interpretation

The expected net return is **negative** (-0.51pp) because:
1. The Pendle AMM is market-efficient — it prices implied APY at approximately the expected
   underlying APY. You're buying at fair value, not at a discount.
2. The std of sUSDe APY (4.5pp) is large relative to the implied yield margin. Half the time
   the market correctly prices in lower-than-current yields.
3. You pay for this risk exposure via: (a) gas/slippage, (b) SC risk premium, (c) time decay
   if you exit mid-term.

**This is the critical K474 finding:** Pendle YT for stablecoin sleeves is **not a reliable
yield enhancement**. It is a yield-direction bet. Expected value is approximately breakeven or
slightly negative after all costs. The 7.5% point-estimate net APY is the _conditional_ return
assuming yield stays high — not the _expected_ return across all scenarios.

### Operational Risk

- YT expires at **exactly $0** at maturity. Any failure to exit or rollover = full residual loss.

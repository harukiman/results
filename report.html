このプロジェクトについて

Hyperliquid と Bybit の永久先物市場で、 資金調達料（funding rate）を使った マーケットニュートラル戦略を AI（Claude）が自律的に研究・検証・本番化するシステム。 ユーザー指示「実運用利益最大化、 止めるまで継続」のもと 24 時間 wave（作業単位）を回している。

研究結果は本リポジトリ harukiman/results に全 push され、 本ダッシュボードが状況の一覧。 取引判断や資金移動は最終的にユーザーが手動承認する設計（LIVE 自動変更禁止）。

⑥ 用語集

wave / K123 / セッション

wave = AI の 1 作業単位。 1 つのアイデア検証または 1 つの戦略本番化が 1 wave。

K123 = 123 番目の wave。 K744〜K799 は今セッションの 56 wave。

セッション = ユーザーが指示を出してから停止指示まで連続実行される一連の wave。

daemon / paper-gate / LIVE

daemon = launchd で常時稼働する 1 つの自動戦略。 84 個並列で動く。

paper-gate = 本番設定はあるが、 実 USDC を入れずに 60 日 paper-trade で検証中の状態。

LIVE = 実 USDC が稼働している状態。 ユーザーが手動で paper → LIVE 昇格を判断。

vertex / alt-alt / cluster

vertex = alt-alt 戦略で使う通貨。 例: PEPE-SOL は PEPE と SOL の 2 vertex。

alt-alt 戦略 = altcoin と altcoin の funding rate 差を取る相対 carry 戦略（K449 ETH-BTC が原型）。

cluster = vertex を mechanism や narrative で分類したグループ。 同 cluster 内 vertex は FR で相関しやすい。

v6.51 / v7.1 / SLEEVE_WEIGHTS

v6.51 / v7.1 = 本番設定（sleeve weights + 取引所 cap）の世代番号。 数字が大きいほど新しい。

SLEEVE_WEIGHTS = 各 daemon の資金配分比率（合計 100%）。 scripts/leverage_manager.py に格納。

K523 / K518 38% / 3 点表記

K523 ルール = 利益予測は必ず保守 / 中央 / 楽観の 3 点で出す（K523 wave で確定）。

K518 38% 実現率 = 過去研究の Sharpe vs 実運用ギャップから導いた haircut 係数。 backtest 値 × 0.38 ≒ 実運用期待値。

§6 厳密ゲート / G1〜G9

§6 厳密ゲート = 戦略 ACCEPT 判定の 9 項目チェック。

  • G1: OOS Sharpe ≥ 1.0
  • G2: permutation p ≤ 0.05（timing alpha 確認）
  • G3: DSR ≥ 0.95
  • G4: walk-forward 全 fold 正
  • G5: 既存戦略との correlation < 0.40
  • G6: trades/yr ≥ 30
  • G7: ann return > 5%
  • G8: cross-venue 確認
  • G9: data history ≥ 180d
L004 / L004_DIFF / G5u / G5j / G5q / G5v（pre-screen rule）

L004 = 単独 carry 偏り。 戦略の方向比率が 80% 超なら hard reject。

L004_DIFF（K782 新）= 差分 carry 偏り。 ペアの差が 70% 以上同方向なら timing alpha 不在で reject。

G5u（K784 新）= FIL-SOL 戦略との signal correlation 0.40 超で reject（storage/data 系の漏れ）。

G5j（K784 新）= SOL-INJ との correlation で reject（gaming 系の漏れ）。

G5q（K792 新）= LDO-SOL との correlation で reject（ETH L2 / DeFi 系の漏れ）。

G5v（K799 新）= 2 銘柄の vol 比 5 倍超なら algebraic 独立でも cluster 依存 → reject。

HIP-3 / HL / Bybit / OKX

HL = Hyperliquid。 永久先物の主要取引所、 deep orderbook。

HIP-3 = HL の non-canonical perp 上場規格。 第三者が listing できる long-tail 通貨が並ぶ。

Bybit = 2 番目の永久先物取引所。 cross-venue 検証や HL cap 超過の hedge venue。

OKX = 3 番目に統合予定（作業 #6）。 HL/Bybit の容量逼迫を解消する役割。

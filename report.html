深い考察: DSR N=710K vs N=100 の解釈ギャップ

DSR (Deflated Sharpe) は試行数 N で罰則がかかる。E[max Sh of N iid] ≈ Z(1-1/N)/√T → 年率換算。観測 Sh=2.78 (T=178日) に対し:

  • N=50: 閾値 1.59 (Sh+2.78 は余裕で超過)
  • N=100: 閾値 1.79 (なお余裕)
  • N=1000: 閾値 2.33 (まだ超過)
  • N=10K: 閾値 2.78 (ちょうど境界)
  • N=100K: 閾値 3.17 (Sh+2.78 < 閾値 → 失格)
  • N=710K: 閾値 3.46 (大幅に失格)

710K試行はパラメータ周辺の連続変動を全て含む。実際の「独立戦略系統」は ~5-10、「独立パラメータ集合」は ~100-1000 程度。実効 N ≈ 100-1000 と仮定すれば G3 は通過。

Auditor 注釈: 「実効N」の正確な推定は本研究の最大の不確実性。710Kは保守的すぎ、100は楽観的すぎる。レジーム別検証 (Wave I で部分実施) や OOS フォワードテストでこのギャップを埋める必要がある。

仮説: 暗号資産市場の構造的非効率性

暗号資産先物市場には2つの構造的特徴がある: (1) 24/7稼働でクローズがないため、伝統的な「オーバーナイトギャップ」や「セッション効果」が存在しない。季節性スキャン（245 configs）が0件Bonferroni有意だった理由。 (2) 参加者の多くがレバレッジトレーダーであり、ボラティリティが急騰すると清算の連鎖が発生し、方向性が増幅される。

この環境で「圧縮→方向性ブレイク」が機能する理由は、低ボラ期間がポジションの蓄積期間に対応するから。レバレッジトレーダーがポジションを構築し、ブレイク時に清算が連鎖し、トレンドが形成される。これは株式市場のスクイーズと同じメカニズムだが、24/7のレバレッジ市場では効果がより顕著。

仮説: SampEnが捉えるもの

サンプルエントロピーは時系列の「規則性」を測定する。低エントロピー = 高規則性は、市場参加者の行動が同期化していることを意味する。全員が同じ情報に反応し、同じ方向に動こうとしている状態。これは「群集行動の前兆」であり、ブレイクアウト前に市場がパターン化する現象を捉えている。

SampEnとVolReg/ATRの相関がほぼゼロ（Pearson <0.05）なのは、異なるタイミングで同じ方向性を検出しているから。VolRegは「ボラティリティの量」を見ているが、SampEnは「価格変動の構造」を見ている。活性化バーの重複はわずか8-10%だが、重複時の方向一致率は95-100%。

  • 5層の独立性: 8生存者は5つの独立なシグナル層を形成する。 (1) リターンボラティリティ圧縮（VolReg: rolling stdが縮小）、(2) 価格レンジ圧縮（ATR ratio: high-low幅が縮小）、(3) エントロピー規則性（SampEn: 時系列パターンが規則的）、(4) 方向的ボラ非対称性（Vol Smile Skew: upside/downside volの比率で恐怖/貪欲を直接測定）、(5) ミームコイン出来高蓄積（MemeMomentum: コミュニティ駆動の出来高パターン — 暗号資産ネイティブ）。5番目の次元は最新発見で、全既存生存者との相関が <0.15 の完全独立シグナル。
  • 時間軸の分散: 日足シグナルと4Hシグナルの相関はほぼゼロ（-0.03〜0.05）。日足は週単位のレジーム遷移を捉え、4Hは日中のマイクロ構造を捉える。同じ銘柄（DOGE）でも時間軸が異なれば独立。
  • 銘柄の分散: DOGE(4戦略) + AVAX(1戦略)。最も高い銘柄間相関はATR_DOGE↔ATR_AVAX の0.435 — 同一シグナル系統でも銘柄固有のボラティリティサイクルにより中程度に抑制。
  • Calmar 15.94の意味: 最大DD -3.8%に対して年率リターン+60.5%。これは$10,000の投資で最悪のドローダウンが$380、年間利益が$6,050ということ。ただしこれはOOS期間（~7ヶ月）のバックテスト結果であり、実運用ではスリッページ・流動性リスク・レジーム変化により劣化する可能性が高い。
  • 最大のリスク: 8生存者中4つがDOGE依存。ただしATR_AVAX（AVAX）、Vol_Smile_Skew（SUI）、MemeMomentum（BONK）により銘柄分散が3通貨に拡大。DOGE集中リスクは軽減されたが、ミームコイン全体の構造変化リスクは依然として存在。

VolReg = close-to-close returns のrolling std比率。終値間の変動を測定 → 日中の動きを無視。ATR_Ratio = (High-Low)/Close のrolling比率。バー内レンジを測定 → 日中のボラティリティ構造を捉える。

相関が0.08しかない理由: close-to-closeが安定していてもbar内では大きく動いている（ヒゲの長い小実体足）場合がある。逆にcloseが大きく変動していてもbar内レンジは小さい（ギャップアップ後の小レンジ足）場合がある。両者は価格変動の異なる次元を見ている。

なぜ5/5シンボルで機能するか: ATR(7)/ATR(56)比率は「直近7バー(28時間)のレンジが過去56バー(9.3日)と比べてどうか」を測定。暗号資産のレンジ圧縮→ブレイクアウトパターンは銘柄を問わず発生する市場構造の普遍的特徴であり、VolRegのようなDOGE特有のマイクロ構造には依存しない。

フォールド2失敗の構造的解釈: 2024Q4-2025Q2はBTCが一方向に強く動いた期間。レンジが持続的に拡大し、圧縮シグナルが発火しにくい＋発火しても即逆転。これはATR圧縮の既知の弱点: 強いトレンド相場では圧縮が稀になり、発火してもホイップソー。しかしフォールド1(4.11)とフォールド3(5.11)の強さから、平均的には十分なエッジがある。

重要な発見: レバレッジが幻のアルファを生成

収益性があるように見えた全ての15分足BTC戦略は、1xレバレッジではマイナスリターンであることが判明。5-10xレバレッジでの見かけの収益性は数学的アーティファクトだった。

アーティファクトの仕組み

Given a strategy with slightly negative expected return at 1x: E[r] = -0.01% per trade At 10x leverage, the asymmetry of compounding creates apparent profit: - Winning trade: +10x gains (compounded on larger base) - Losing trade: -10x losses (compounded on smaller base) But the asymmetry of % gains vs % losses creates a positive bias: +10% gain then -10% loss = 0.99x (net loss) But with leverage and many trades, the SEQUENCE matters, and strategies that happen to cluster wins can appear profitable. The key test: Strip leverage to 1x. If negative, there is no edge.

なぜ順列検定だけでは不十分か

順列検定はOOSエクイティカーブのシャープがその特定の期間内で偶然発生し得るかを評価する。戦略のエッジが異なるマーケットレジーム間で安定しているかはテストしない。

OOS期間がたまたま強いトレンド相場である場合 (2025年11月-2026年5月の窓のように)、あらゆるトレンドフォロー戦略が低いp値で強いOOS結果を示す — 真のエッジがあるかどうかに関わらず。全トレンドフォロー戦略の38/486のISマイナス→OOSプラス設定がこれがレジーム効果であることを確認。

重要なテスト: IS→OOSの一貫性。真のエッジ (VolReg_opt, Regime_V3) はIS期間とOOS期間の両方で正のリターンを示す。そのエッジは構造的 (ボラティリティ圧縮検出) であり、レジーム依存 (トレンド市場でのトレンドフォロー) ではない。

経験則: インサンプルでマイナスだがアウトオブサンプルでプラスの戦略は、優れた順列検定p値があっても信用してはならない。統計テストの前提条件としてIS/OOSの一貫性を要求すること。
